# Security Policy

Report security vulnerabilities privately by emailing `security@example.com`. Do not open a public issue for suspected vulnerabilities.

Include:

- Affected version or commit.
- Reproduction steps.
- Impact and prerequisites.
- Any logs or fixtures that help reproduce the issue.

The maintainers will acknowledge reports within 7 days where possible, coordinate a fix, and publish advisory details after users have had a reasonable upgrade window.

Norn may require sensitive host access, especially Docker API access. Deployment hardening issues are welcome even when they are documentation or configuration risks rather than code vulnerabilities.
